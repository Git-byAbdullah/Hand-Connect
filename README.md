# ✋ Hand-Connect

An AI-assisted interactive hand-tracking AR experience built with HTML, JavaScript, MediaPipe Hands, Canvas, and Web Audio API.

## ✨ Features

* Real-time hand tracking using MediaPipe Hands
* Supports up to two hands
* Hand gesture detection
* Pinch, open-hand, and fist detection
* Hand spread percentage tracking
* Interactive particle effects
* Neon visual effects and shockwaves
* Multiple visual themes
* Matrix-style background animation
* Web Audio API sound effects
* Camera-based AR interaction
* Responsive full-screen interface

## 🛠️ Technologies

* HTML5
* JavaScript
* MediaPipe Hands
* Canvas API
* Web Audio API
* Camera API

## ▶️ How to Run

1. Clone the repository.
2. Open `hand Connect.html` in a modern web browser.
3. Allow camera access when prompted.
4. Start the experience and interact with the visual effects using your hands.

> Camera permissions are required for hand tracking.
